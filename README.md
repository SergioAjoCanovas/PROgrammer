# <p align="center">ProGrammer</p>

## 🧑‍💻 Sobre el proyecto

**ProGrammer** es una aplicación web desarrollada como proyecto colaborativo por un equipo de 3 personas. Se trata de una plataforma que combina un **portal de empleo con una red social profesional**, orientada al ámbito tecnológico y de desarrollo de software.

La aplicación permite a los usuarios conectar entre sí, compartir proyectos y oportunidades laborales, así como interactuar mediante diferentes funcionalidades sociales integradas dentro del sistema.

Este proyecto nació como **Proyecto de Fin de Ciclo**, con el objetivo de aplicar conocimientos avanzados de desarrollo web, arquitectura de software y trabajo en equipo en un entorno real de desarrollo colaborativo.

---

## ✨ Características principales

- Publicación y gestión de ofertas de empleo.
- Sistema de postulaciones a trabajos.
- Red social profesional con perfiles de usuario.
- Sistema de amistad y seguimiento entre usuarios.
- Chat en tiempo real entre usuarios.
- Publicación y gestión de proyectos.
- Sistema de notificaciones y avisos.
- Edición y personalización del perfil de usuario.

---

## 🧠 Objetivos del proyecto

- Desarrollo de una plataforma web full stack funcional y escalable.
- Aplicación de arquitectura cliente-servidor.
- Integración de comunicación en tiempo real.
- Gestión de bases de datos relacionales.
- Trabajo colaborativo en un entorno de desarrollo real.
- Diseño de una experiencia de usuario intuitiva y completa.

---

## 🛠️ Tecnologías y enfoque

El proyecto ha sido desarrollado aplicando buenas prácticas de programación orientada a objetos, separación de responsabilidades y diseño modular, con el objetivo de garantizar mantenibilidad y escalabilidad del sistema.
